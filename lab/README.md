# QuantMind — متتبع المحفظة ومخطط الشراء الشهري (v0.1)

أول طوبة في النظام: بيسجل العمليات، بيقيّم المحفظة، وبيطلع كل شهر **قائمة شراء** تقرّب التوزيع من المستهدف من غير بيع.
التنفيذ نفسه (الشراء والبيع) بيفضل يدوي في التطبيق.

- Python 3.10+ من غير أي مكتبات خارجية.
- البيانات كلها ملفات CSV/JSON تتقري وتتعدل بالإيد.
- دفترين منفصلين: `paper` للتجربة و`real` للفلوس الحقيقية. الأسعار مشتركة بينهم.

## التشغيل

```bash
cd quantmind
python -m unittest discover -s tests -t .     # 21 اختبار
python scripts/simulate.py                     # محاكاة 14 شهر بأسعار افتراضية -> reports/sample-simulation.html
python -m qm status                            # حالة الدفتر التجريبي
```

`--book real` بيحوّل للدفتر الحقيقي، و`--date 2026-12-20` بيحدد التاريخ (الافتراضي: النهارده).

## الروتين الشهري (5 دقايق)

```bash
# 1) حدّث الأسعار. الأسهل: اكتب الرصيد اللي ظاهر في التطبيق لكل بند
python -m qm --book real mark CASH 1217.50
python -m qm --book real mark GOLD 412.30
python -m qm --book real mark INDEX 2140.00    # قيمة سلة الأسهم كلها (بعد فتح الشريحة)

# 2) سجّل الإيداع الجديد وشوف قائمة الشراء
python -m qm --book real deposit 2000
python -m qm --book real status

# 3) نفّذ في التطبيق، وبعدها سجّل اللي اتنفذ فعلًا
python -m qm --book real buy CASH  --amount 1600                    # 1,200 نقد + 400 نصيب الأسهم المحجوز
python -m qm --book real buy GOLD  --amount 400 --units 0.0609      # الجرامات اللي استلمتها
# بعد فتح شريحة الأسهم: كل 2,000 جنيه = سهم واحد، والسلة كلها بند واحد بيتقيّم بالقيمة
python -m qm --book real buy INDEX --amount 2000 --fee 5.5

# 4) التقرير
python -m qm --book real report        # reports/real-YYYY-MM-DD.html + .json
```

لو عايز تشوف القائمة قبل ما تحوّل الفلوس: `python -m qm status --add 2000`.

## الأوامر

| الأمر | بيعمل إيه |
|---|---|
| `init` | ينشئ الدفتر ويبدأ سعر أدوات النقد من 1.0 |
| `deposit N` / `withdraw N` | إيداع أو سحب من الرصيد |
| `buy INST --amount N [--units U \| --price P] [--fee F \| --fee-pct X]` | شراء. `amount` هو كل اللي اتدفع شامل الرسوم |
| `sell INST --units U \| --all [--price P]` | بيع، والصافي بيرجع للرصيد |
| `income INST N` | عائد اتصرف كاش (شهادة، إيجار) |
| `mark INST VALUE` | الرصيد اللي ظاهر في التطبيق، والسعر بيتحسب منه |
| `price INST P` | تسجيل سعر مباشر (مثلًا سعر وثيقة) |
| `accrue INST --rate 0.18` | ينمّي السعر بعائد سنوي لحد التاريخ (للدفتر التجريبي) |
| `status [--add N]` | الحالة وقائمة الشراء في الترمنال |
| `report [--add N] [--out FILE]` | تقرير HTML عربي + نفس البيانات JSON |
| `fetch` | أسعار مرجعية من الإنترنت (شوف الملاحظة تحت) |

الأدوات المعرّفة: `CASH` `CERT` `GOLD` `INDEX` `ACTIVE` `REALESTATE` `BTC` (في `config/portfolio.json`).
`INDEX` هو سلة الأسهم المفلترة كبند واحد (الاسم قديم من أيام صندوق المؤشر، واتساب زي ما هو علشان الدفاتر المسجلة).

## القواعد اللي النظام بيطبقها

كلها في `config/portfolio.json` وتتغير من هناك:

- **المراحل:** أقل من 10,000 ← نقد 60 / ذهب 20 / أسهم 20. من 10,000 ← 50 / 20 / 20 / نشط 10. من 25,000 ← 40 / 15 / 15 / 10 / عقار 20.
- **شريحة الأسهم مقفولة ببوابة** (`buckets.index.gate.closed`) لحد ما الـ Screener يجهز ونتيجة الاستفتاء في الأسهم المختلطة تيجي. طول ما هي مقفولة نصيبها بيتحجز في النقد والنظام بيعرض المبلغ. بعد الفتح: شراء مجمّع، سهم واحد كل 2,000 جنيه.
- **الشراء بالإضافات بس:** الفلوس الجديدة بتروح للبنود الناقصة عن نسبتها. النظام مش بيقترح بيع لإعادة التوازن.
- **الحصص الكاملة:** الأسهم (2,000) والعقار (5,000) والكريبتو (400) بيتشتروا لما المبلغ يكمّل. قبل كده نصيبهم بيتركن في النقد، وبعدها النظام يقترح تحويل.
- **الهبوط:** هبوط المحفظة 10% من القمة = تنبيه بعدم زيادة المبلغ. هبوط شريحة الأسهم 25% من أعلى سعر = مراجعة تشخيصية (السيستم وكل سهم). الإيداع والشراء مستمرين في الحالتين؛ مفيش قاعدة بتوقف الشراء.
- **خط الأساس:** نفس الإيداعات لو كانت كلها في صندوق النقد. لو المحفظة أقل منه بأكتر من 2% بيطلع تنبيه.
- **الكريبتو مقفول افتراضيًا** (`"crypto": {"enabled": false}`). لو اتفتح: 8% بعد ما المحفظة تعدّي 5,000، مع قاعدة خروج متوسط 200 يوم.
- **المراجعة:** قبل 150 يوم الحكم "بدري". بعدها: "كمّل وزوّد" أو "كمّل من غير زيادة".

مؤشر الأداء (NAV) بيستبعد أثر الإيداعات، فالهبوط والربح بيتحسبوا على أداء الاستثمار نفسه مش على حجم المحفظة.

## حدود النسخة دي

- **`fetch` متجربش على الإنترنت.** البيئة اللي اتبنى فيها النظام مكانش فيها وصول للمواقع دي. الكود مكتوب على توثيق المصادر (Binance، open.er-api، gold-api)، وأول تشغيل على جهازك هو الاختبار الحقيقي. النظام مش معتمد عليه: `mark` و`price` كفاية.
- أسعار صناديق ثاندر مالهاش API عام، فبتتسجل يدوي بـ `mark`.
- سعر الذهب المرجعي من `fetch` بيتحسب من السعر العالمي والدولار الرسمي، والسعر المحلي غالبًا أعلى منه.
- التقرير حساب آلي على البيانات المسجلة، ومش توصية استثمارية.
